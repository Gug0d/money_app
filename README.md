1. Клонирование проекта

Сначала необходимо скачать проект на компьютер:
git clone <ссылка-на-репозиторий>

После этого нужно перейти в папку проекта:
cd finity-app

2. Установка зависимостей

Для установки всех необходимых зависимостей выполните команду:
npm install

Если в проекте используется Yarn, можно выполнить:
yarn install

3. Запуск проекта

Для запуска приложения через Expo выполните команду:
npx expo start

После запуска в терминале появится QR-код. Его можно отсканировать через приложение Expo Go на мобильном устройстве.

Также проект можно запустить на эмуляторе:
npm run android

или

npm run ios

4. Запуск веб-версии

Если проект поддерживает запуск в браузере, используйте команду:
npm run web

5. Возможные проблемы

Если после установки зависимостей проект не запускается, можно очистить кэш Expo:
npx expo start -c

Если приложение не запускается, его можно запустить с помощью:
 npx expo start --offline

Если возникают ошибки с зависимостями, можно удалить папку node_modules и файл package-lock.json, после чего заново установить зависимости:
rm -rf node_modules package-lock.json
npm install

Для Windows можно удалить эти файлы вручную через проводник или выполнить команду в PowerShell:
Remove-Item -Recurse -Force node_modules
Remove-Item -Force package-lock.json
npm install
