Инструкция по запуску проекта
1. Что необходимо установить перед запуском

Перед запуском проекта на компьютере должны быть установлены следующие программы:

Node.js LTS
Node.js необходим для работы JavaScript/TypeScript-проекта и установки зависимостей через npm. Вместе с Node.js устанавливается пакетный менеджер npm.
Git
Git нужен для клонирования проекта из удалённого репозитория с помощью команды git clone.
Редактор кода
Для просмотра и редактирования проекта можно использовать Visual Studio Code или другой удобный редактор кода.
Expo Go
Если приложение запускается на физическом телефоне, на мобильное устройство необходимо установить приложение Expo Go. Оно позволяет открыть проект через QR-код без отдельной сборки приложения.
Android Studio
Android Studio необходим, если проект планируется запускать на Android-эмуляторе. В Android Studio нужно установить Android SDK и создать виртуальное устройство через Device Manager.
Xcode
Для запуска приложения на iOS-симуляторе необходим Xcode. Он доступен только на macOS, поэтому команда запуска iOS обычно используется только на компьютерах Apple.

После установки программ можно проверить их наличие через терминал:

node -v
npm -v
git --version

Если команды выводят версии программ, значит они установлены корректно.

2. Клонирование проекта

Сначала необходимо скачать проект на компьютер. Для этого нужно открыть терминал и выполнить команду:

git clone <ссылка-на-репозиторий>

Вместо <ссылка-на-репозиторий> необходимо вставить ссылку на GitHub-репозиторий проекта.

После клонирования нужно перейти в папку проекта:

cd finity-app

Если проект находится в другой папке, необходимо перейти именно в ту директорию, где расположен файл package.json.

3. Установка зависимостей

После перехода в папку проекта необходимо установить все зависимости:

npm install

Эта команда считывает список библиотек из файла package.json и устанавливает их в папку node_modules.

Если в проекте используется Yarn, можно выполнить:

yarn install

Обычно для проекта достаточно использовать один пакетный менеджер. Если в проекте есть файл package-lock.json, лучше использовать npm install. Если есть файл yarn.lock, можно использовать yarn install.

4. Подготовка переменных окружения

Если в проекте используются Firebase, API-ключи или другие внешние сервисы, может потребоваться файл .env или конфигурационный файл.

Обычно такие файлы не загружаются в GitHub, потому что содержат личные ключи и данные доступа. В этом случае нужно проверить, есть ли в проекте файл-пример, например:

.env.example

Если такой файл есть, его нужно скопировать, переименовать в .env и заполнить нужными значениями.

5. Запуск проекта через Expo

Для запуска приложения через Expo нужно выполнить команду:

npx expo start

После запуска в терминале откроется Expo Dev Server и появится QR-код.

Дальше есть несколько вариантов запуска:

Запуск на телефоне
Нужно установить приложение Expo Go на телефон и отсканировать QR-код.
Телефон и компьютер должны находиться в одной сети Wi-Fi.
Запуск на Android-эмуляторе
Сначала нужно открыть Android Studio, создать и запустить эмулятор.
После этого в терминале с Expo можно нажать клавишу:
a

Или выполнить команду:

npm run android
Запуск на iOS-симуляторе
Этот вариант доступен только на macOS при установленном Xcode.
Для запуска можно нажать клавишу:
i

Или выполнить команду:

npm run ios
Запуск веб-версии
Если проект поддерживает запуск в браузере, можно выполнить команду:
npm run web

Или после запуска Expo нажать клавишу:

w
6. Основные команды запуска

Для обычного запуска проекта используется команда:

npx expo start

Для запуска с очисткой кэша:

npx expo start -c

Для запуска в офлайн-режиме:

npx expo start --offline

Для запуска на Android:

npm run android

Для запуска на iOS:

npm run ios

Для запуска в браузере:

npm run web
7. Возможные проблемы и способы решения

Если после установки зависимостей проект не запускается, можно очистить кэш Expo:

npx expo start -c

Если возникают ошибки с зависимостями, можно удалить папку node_modules и файл package-lock.json, после чего заново установить зависимости:

rm -rf node_modules package-lock.json
npm install

На Windows эти файлы можно удалить вручную через проводник, после чего снова выполнить команду:

npm install

Если команда npm run android не работает, необходимо убедиться, что Android Studio установлена, Android SDK настроен, а эмулятор создан и запущен.

Если приложение не открывается через QR-код, нужно проверить, что компьютер и телефон подключены к одной сети Wi-Fi. Также можно попробовать изменить режим подключения в Expo Dev Server, например использовать режим Tunnel.

Если проект использует переменные окружения, нужно убедиться, что файл .env создан и заполнен корректно.

8. Краткий порядок запуска

В общем виде запуск проекта выполняется следующим образом:

git clone <ссылка-на-репозиторий>
cd finity-app
npm install
npx expo start

После этого приложение можно открыть через Expo Go на телефоне, через Android-эмулятор, iOS-симулятор или в браузере, если проект поддерживает веб-версию.
